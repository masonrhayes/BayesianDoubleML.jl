BayesianDoubleML VMP example

begin
    using BayesianDoubleML
    using StableRNGs
    using RxInfer
    using PlutoUI
end

Data generation

Let's generate data as per Section 6 DiTraglia and Liu (2025).

begin
    # Define parameters
    n = 200
    p = 100
    alpha_true = 2.0

    rng = StableRNG(42)

    # Generate data as DataFrame
    df = make_plr_DTL2025(n, p, 2.0; alpha = alpha_true, rng = rng)
end;

We then define the BDMLModel, using the hierarchical model (BDML-Hier) from the paper:

As per Section 6 of the paper, the BDML-Hier model "allows different standard deviations in the normal shrinkage priors for \(\delta\) and \(\gamma\) ... with a hierarchical prior that places independent Inverse-Gamma(2, 2) hyper-priors on \(\sigma^2_\delta\) and \(\sigma^2_\gamma\)."

model = BDMLModel(df, :y, :d; model_type = :hier)
BDMLHierarchicalModel (not fitted)
  Observations: 200
  Covariates: 100

And we then fit the model using Variational Message Passing (VMP).

In this example, we first try using the manual method using coordinate ascent (ManualCoordinateAscentVMP()).

Whether using this method or the RxInfer method, the VMP implementation has the advantage of blazingly fast inference, because it:

  • Applies an adjusted model using only conjugate-exponential distributions, simplifying inference.

  • Relies only on the sufficient statistics of the data so that the fitting time does not scale with \(n\).

It performs equally well as ADVI but significantly faster; however, it shares the same limitation — it is accurate when \(p\) is large but still smaller than \(n\) (here \(p/n = 0.5\)), and degrades when \(p >= n\) (\(p >> n\)).

Reported \(α\) uncertainty applies an effective residual degrees-of-freedom correction to the mean-field covariance posterior. The calibrated posterior is result.posterior.Σ, while result.posterior.Σ_vmp retains the raw variational posterior and result.posterior.effective_df records the correction (also shown by summary).

fit!(
    model,
    VMP(; backend = ManualCoordinateAscentVMP()),
    n_iterations = 50,
    n_draws = 2000,
    show_progress = true
)

As shown from the results below, VMP's approximation to the posterior is a good approximation for this particular problem. However, in some scenarios where \(p >= n\) (more covariates than observations), VMP performs more poorly.

Problems less suitable to VMP

As we see above, for this problem, as with ADVI, VMP is a good fit where \(p\) is large but \(p < n\) (\(p = 100\), \(n = 200\) above); VMP is able to reach a good approximation, at least with this data generation process. The true causal effect is 2.0, and the above model estimated 1.96.

However, VMP does not yield a good approximation where \(p >= n\).

df2 = make_plr_DTL2025(n2, p2, 2.0; alpha = alpha_true, rng = rng);
model2 = BDMLModel(df2, :y, :d; model_type = :hier)

RxInfer backend

Instead of the manually-implemented VMP, we can also fit the same model using RxInfer.jl as the backend. The two deliver nearly identical results, with the manual implementation being slightly more performant.

We could also fit the exact same model using RxInfer as a backend:

begin
    model_rx = BDMLModel(df, :y, :d; model_type = :hier)

    # Fit using RxInfer
    @time fit!(
        model_rx,
        VMP(; backend = RxInferVMP()),
        n_iterations = 50,
        show_progress = true,
    )

end

begin
    summary(model_rx)
    coeftable(model_rx)
end
